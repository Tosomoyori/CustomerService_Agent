# 三语智能客服 Agent · 方案概述

> 面向业务评委 / 面试演示的一页式说明。技术细节见项目 README，工作流低代码迁移见《Dify 工作流映射》。
> 业务背景为香港跨境通信运营商（漫游 / 大湾区计划 / 企业专线），示例数据为业务结构演示，不涉及具体公司。

## 1. 解决什么问题

香港跨境通信客服面临三个现实约束：

1. **语言**：香港用户以粤语、港式繁体提问为主，内地漫游用户用普通话，国际访客用英语——单一语言客服必然流失触达；
2. **资费敏感**：漫游包价格、按金、月费一旦答错，直接引发监管投诉与信任损失；
3. **两套客群一套服务**：C 端用户查漫游/大湾区计划，B 端企业问跨境组网（专线/SD-WAN），传统 IVR 难以兼顾，人工客服成本高。

三语智能客服 Agent 统一承接：**C 端做咨询与推荐，B 端做方案顾问与商机留资，高危动作（工单、转人工）全链路可追溯**。

## 2. 核心能力与业务价值

| 能力 | 场景示例 | 业务价值 |
|---|---|---|
| 三语一致服务 | 「漫遊日本幾多錢一日？」/「国际漫游怎么开通？」/ "How to top up my prepaid SIM?" | 同一套知识库承接三语，无语言孤岛 |
| 资费零幻觉 | 推荐套餐只引用工具查询结果，LLM 话术金额越界自动回退模板 | 资费错误率归零导向，投诉风险可控 |
| 套餐智能推荐 | 「我是来港的内地学生，预算 100 元」→ 内地学生计划 + 大湾区备选 | 咨询到转化，减少人工推荐成本 |
| B 端方案顾问 | 「连锁零售 20 家门店，要性价比高的组网」→ SD-WAN 智选专线建议 + 留资 | 商机自动登记（脱敏落库），缩短响应链路 |
| 投诉与转人工 | 收费争议/网络故障分类 → 工单编号 + 1 个工作日跟进承诺 | 情绪兜底，转人工排队编号可追溯 |
| 知识问答可溯源 | 「eSIM 怎么开通？」→ 抽取式回答 + 知识库出处标注 | 回答有据可查，审计友好 |

## 3. 两个客群，一条工作流

```
用户输入（粤/普/英）
   │
   ▼
识别语言 ──▶ 路由意图 ──┬─ C端：漫游咨询 ──▶ 目的地+天数 ──▶ 漫游包/大湾区计划 + 开通提示
                       ├─ C端：套餐推荐 ──▶ persona/预算  ──▶ TOP2 套餐（含内地号码等权益）
                       ├─ C端：知识问答 ──▶ BM25 检索    ──▶ 抽取式回答 + 来源
                       ├─ B端：企业方案 ──▶ 行业×站点×带宽 ──▶ 方案建议 ──▶ 留资登记
                       ├─ 投诉工单  ──▶ 分类 + 联系方式 ──▶ 工单落库（脱敏）
                       ├─ 转人工    ──▶ 排队编号（永远可退出任何流程）
                       └─ 闲聊问候  ──▶ 能力引导
   │
   ▼
护栏（PII 脱敏 · 金额溯源 · 免责声明）──▶ 回复 + 推理链路 trace
```

多轮体验的关键：企业留资与工单登记是**跨轮槽位流程**——即使用户下一轮只回复一个电话号码，流程也能正确延续；「转人工」在任意环节可用，保证用户永远有出口。

## 4. 实测结果（离线）

| 维度 | 结果 |
|---|---|
| 语言识别（粤/普/英，36 例） | 100.0% |
| 意图路由（36 例，纯规则） | 100.0% |
| 知识检索 Hit@1 / Hit@3 / MRR（18 例） | 94.4% / 100.0% / 0.907 |
| 护栏自检（PII + 金额溯源） | 7/7 |
| 自动化测试 | 72 passed |

全部指标在 **Mock 模式**（零外部 API 依赖）下测得，评测可复现；真实模式仅把「话术组织」交给 LLM，工具查询、金额校验、脱敏逻辑与 Mock 完全一致。

## 5. 落地路径建议

1. **P0（当前原型）**：示例数据 + Mock 模式，验证流程与评测体系；
2. **P1（试点）**：接入运营商官方资费接口与真实知识库，Live 模式接 LLM（OpenAI 兼容协议，DeepSeek/Qwen 等国产模型均可），上线 Web/微信渠道；
3. **P2（扩展）**：检索升级混合召回（BM25 + 向量），话术质量引入 LLM judge 评测，会话存储外置（Redis）支持多副本，接入 Dify 类低代码平台供运营侧调整话术与流程。

## 6. 合规与风险控制

- **隐私**：PDPO 数据最小化——PII 仅脱敏存储（日志与落库同标准），公开热线白名单保护；
- **资费**：金额唯一来源是工具查询，回复侧做溯源校验，越界即回退；含金额回复统一附「以官方渠道为准」；
- **兜底**：检索低分/无数据不猜答案，引导客服热线或转人工；
- **审计**：每轮回复携带推理链路 trace（语言 → 意图 → 工具 → 生成 → 护栏），会话日志脱敏后留档。
