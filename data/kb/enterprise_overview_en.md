# Enterprise Solutions Overview (EN)

## Global Connectivity
The provider's global business platform delivers carrier-grade international connectivity for enterprises: IEPL (International Ethernet Private Line) for low-latency point-to-point links, IPLC legacy circuits, MPLS VPN for any-to-any multi-site networking, and SD-WAN Smart Select for fast branch deployment with hybrid (dedicated + Internet) links.

## Cloud and Data Center
Cross-border Cloud Connect (high-speed channel) interconnects on-premises and multi-cloud resources across the mainland and overseas. Hong Kong cloud data centers offer T3+ colocation, private cloud and cabinet rental for enterprises landing their IT base in Hong Kong.

## IP Transit and IoT
IP Transit offers BGP-based carrier-grade internet access for operators and content providers. Global IoT connectivity provides multi-country roaming SIM/eSIM with a connection management platform and shared data pools for asset tracking, connected vehicles and metering.

## How to Choose
- Two-site low latency: IEPL / IPLC
- Many branches, budget-sensitive: SD-WAN
- Three or more sites, intranet: MPLS VPN
- Cloud interconnect: Cross-border Cloud Connect
- Landing IT base in HK: Hong Kong Data Center
- Massive cross-border devices: Global IoT
